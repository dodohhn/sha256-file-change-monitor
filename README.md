German:

# SHA-256 File Change Monitor

Ein kleines Python-Skript, das Dateien in einem Ordner anhand ihrer SHA-256-Hashes
prüft und neue, geänderte sowie gelöschte Dateien meldet.

## Voraussetzungen

- Python 3

## Verwendung

Passe im Skript die Ordner- und Dateipfade an und starte es mit:

```bash
python script.py
```

Englisch:

A small Python script that checks files in a folder based on their SHA-256 hashes
and reports new, modified, and deleted files.

## Prerequisites

- Python 3

## Usage

Adjust the folder and file paths in the script and run it with:

```bash
python script.py
```
